# PIP (PipelineGen 2026)

Компактное нативное десктопное приложение для Windows на чистом **.NET Framework 4.8 (WPF)** без сторонних библиотек для создания и повторного запуска многошаговых AI-пайплайнов через **OpenRouter API**.

- **Один исполняемый файл:** `wpf/bin/Release/PipelineGenWpf.exe` (~185 КБ)
- **Зависимости:** 0 сторонних пакетов (только встроенный .NET Framework 4.8 в Windows)
- **Интерфейс:** компактный нативный Windows-стиль без лишнего визуального шума

---

## Возможности

### Два визуально разделенных режима
- **Запуск (синий акцент / нейтральный фон `#F3F3F3`):**
  - Загрузка файлов и изображений через выбор файла, Drag-and-Drop или вставку скриншота из буфера обмена (`Ctrl+V`).
  - Последовательное выполнение всей цепочки (`▶ Запустить`), запуск/перезапуск с конкретного шага, сброс полей (`Сбросить`).
  - Пауза для ручной проверки и редактирования результата между шагами (Human-in-the-loop).
  - Markdown-отображение результатов и поддержка тегов `<copy>...</copy>` с кнопками быстрого копирования фрагментов.
  - Продолжение диалога с итоговым результатом и сохранение удачного уточнения как нового шага пайплайна.
- **Конструктор (теплый янтарный акцент / фон `#F7F3EA`):**
  - Добавление, перестановка и удаление шагов трех типов: **Текст**, **Файл / Изображение**, **AI-шаг (OpenRouter)**.
  - Вставка макросов `{{step_1}}`, `{{step_2}}` и тега `<copy>` в позицию курсора промпта.
  - Предупреждение в реальном времени, если на шаг с изображением назначена текстовая модель без `[Vision]`.
  - Автосохранение изменений проекта (`Ctrl+S` для принудительного сохранения).

### Настройки и модели OpenRouter
- Локальное хранение API-ключа и реестра моделей.
- Загрузка полного каталога моделей OpenRouter с определением поддержки `[Vision]`.
- Проверка доступности каждой модели кнопкой `Тест`.
- Автоматические повторы при временных ошибках (`429`, `502`, `503`, `504`) и понятные сообщения об ошибках (включая несовместимость текстовой модели с изображениями).

### Хранение данных и документация
- Данные хранятся в `%APPDATA%\PipelineGen2026\`:
  - `config.json` — API-ключ, модель по умолчанию и список моделей.
  - `projects/<project_id>/project.json` — структура пайплайна.
  - `projects/<project_id>/README.md` — автогенерируемое описание пайплайна (просмотр по кнопке `README`).
- При первом запуске WPF-версия автоматически подхватывает существующие `config.json` и `projects/` из старых папок, если они есть.

## Сборка и запуск (WPF)

Требуется только Windows с установленным **.NET Framework 4.8** (встроен в Windows 10/11). Visual Studio или .NET SDK не нужны.

### Через `build.bat`
```cmd
cd wpf
build.bat
```

### Через MSBuild напрямую (Git Bash / cmd)
```bash
/c/Windows/Microsoft.NET/Framework64/v4.0.30319/MSBuild.exe wpf/PipelineGenWpf.csproj -p:Configuration=Release -t:Rebuild -v:minimal
```

Собранный бинарник: `wpf/bin/Release/PipelineGenWpf.exe`.

## Структура WPF-проекта (`wpf/`)

- `App.xaml(.cs)` — запуск приложения, сетевые настройки (`TLS 1.2/1.3`, `Expect100Continue = false`, лимит соединений).
- `MainWindow.xaml(.cs)` — боковая панель проектов, верхняя панель с переключателем `Запуск` / `Конструктор`, статус-бар и журнал событий.
- `Views/PipelineRunnerView.xaml(.cs)` — экран запуска пайплайна, подстановка макросов, передача изображений (Vision), доработка итогового результата.
- `Views/PipelineBuilderView.xaml(.cs)` — конструктор шагов, выбор моделей, предупреждение о Vision, вставка макросов.
- `Views/SettingsWindow.xaml(.cs)` — API-ключ, пресеты, загрузка каталога OpenRouter и тест моделей.
- `Views/HumanInputWindow.xaml(.cs)` — модальное окно проверки/редактирования промежуточного результата.
- `Views/ReadmeWindow.xaml(.cs)` — просмотр и копирование `README.md` активного проекта.
- `Controls/CopyableContentControl.xaml(.cs)` — отображение Markdown и кликабельных блоков `<copy>...</copy>`.
- `Services/OpenRouterService.cs` — HTTP-клиент OpenRouter (`HttpClient` с gzip/deflate, ретраями и разбором ошибок).
- `Services/StorageService.cs` — работа с `%APPDATA%\PipelineGen2026\`, миграция и генерация `README.md`.
- `Services/JsonHelper.cs` — JSON-сериализация/десериализация на встроенном `JavaScriptSerializer`.
- `Services/FileHelper.cs` — загрузка файлов/изображений с диска и из буфера обмена.
- `Services/MarkdownFlowBuilder.cs` — конвертация Markdown в `FlowDocument`.
- `Models/PipelineModels.cs` — модели данных (`AppConfig`, `ModelConfig`, `Project`, `StepDefinition`, `ChatMessageItem`, `LogEntry`).
- `Resources/Styles.xaml`, `Resources/app.ico` — компактные Windows-стили и красная иконка `PIP`.
