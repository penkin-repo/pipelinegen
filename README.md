# AI Pipeline Studio (2026)

Локальное десктопное приложение на **Wails v2 (Go + React / Vite / Tailwind CSS)** для создания, настройки и повторного выполнения многошаговых AI-пайплайнов через OpenRouter API.

В проекте используется менеджер пакетов **`pnpm`**.

---

## 🚀 Основные возможности

1. **Два режима работы (Вариант А):**
   - 🛠️ **«Конструктор шагов»:**
     - Создание цепочки блоков: **Текст**, **Файл / Vision**, **AI-обработка (OpenRouter)**.
     - Подстановка результатов предыдущих шагов через удобные кликабельные макросы `{{step_1}}`, `{{step_2}}`.
     - Выбор проверенной модели из личного реестра или ручной ввод ID модели.
     - Тестирование каждого отдельного шага без запуска всей цепочки.
     - Опция **«Приостанавливать пайплайн для ручной проверки/ввода пользователем»** (Human-in-the-loop).
   - 🚀 **«Запуск (Раннер)»:**
     - Фокусированный режим для рутинного использования без лишних настроек.
     - Зона Drag-and-Drop для входных картинок (Vision) и документов или поле для ключевых слов/текста.
     - Кнопка **«▶ Запустить пайплайн»** с пошаговым спиннером выполнения.
     - Интерактивное всплывающее окно (модалка) при необходимости ручной проверки или ввода данных между шагами.
     - Итоговый результат с Markdown-рендером и кнопкой копирования.

2. **Реестр проверенных моделей (Настройки):**
   - Сохранение API-ключа OpenRouter локально в `config.json`.
   - Добавление моделей из каталога популярных пресетов (Gemini 2.5 Flash/Pro, Claude 3.7 Sonnet, Claude 3.5 Haiku, GPT-4.1, GPT-4o-mini, DeepSeek R1, Llama 3.3 70B, Qwen 2.5 VL) или произвольного ID.
   - **Автоматическая проверка доступности (Healthcheck):** при добавлении модели приложение отправляет тестовый пинг к OpenRouter с вашим ключом. Добавляются только рабочие модели со статусом `✓ Verified`.

3. **Сохранение проектов и генерация `README.md` (нативно в Go):**
   - Проекты сохраняются в папке `projects/<id>/project.json`.
   - Автоматическая нативная генерация `projects/<id>/README.md` со структурой, шагами, промптами и блоком **«Контекст для ИИ»**.
   - Просмотр и копирование документации по кнопке `README.md` в шапке.

4. **Журнал событий (Логгер):**
   - Нижняя выезжающая панель с подробными логами запросов к OpenRouter, кодами ошибок и временем ответов.

## 🛠️ Запуск и разработка

### Требования
- **Go** (1.21+)
- **Node.js** и **pnpm**
- **Wails CLI v2**

### Запуск в режиме разработки (Live Dev)
```bash
wails dev
```
Откроется нативное окно Wails с Hot Reload.

### Сборка production exe
```bash
wails build
```
Готовый исполняемый файл создается в папке:
`build/bin/PipelineGen 2026.exe`

## 📁 Структура проекта
- `app.go` — Go бэкенд (OpenRouter клиент, валидация моделей, хранилище проектов, генератор `README.md`, системный диалог файлов).
- `main.go` — точка входа Wails v2.
- `projects/` — локальные папки сохраненных пайплайнов и автогенерируемых `README.md`.
- `config.json` — локальный конфиг с API-ключом и проверенными моделями.
- `frontend/` — интерфейс на React 18, Vite, Tailwind CSS и TypeScript.
  - `src/components/PipelineRunner.tsx` — экран выполнения готового пайплайна.
  - `src/components/PipelineBuilder.tsx` — визуальный конструктор шагов и макросов.
  - `src/components/SettingsModal.tsx` — управление ключом и реестр проверенных моделей с тестом API.
  - `src/components/HumanInputModal.tsx` — окно проверки/ввода промежуточных данных.
  - `src/components/ReadmeModal.tsx` — окно просмотра автогенерируемого README проекта.
  - `src/components/LogDrawer.tsx` — логгер сетевых запросов и ошибок.
